## Running locally

Open `index.html` in a browser with an internet connection. The assignment loads jQuery 4.0.0 and Bootstrap from their CDNs. Search, toasts, counters and loading states are implemented in the external `js/jquery-assignment.js` file. On a laptop, use `Left/Right Arrow` to move between the site's pages; the shortcut does not open browser tabs.

## Earlier project features

The previous JavaScript features remain in their original `js/` files: form validation, accordion, subscription popup, theme, date/time, animal filtering, ticket wizard, rating, random facts, keyboard navigation and a custom short notification chime for site interactions. Use the sound toggle to turn effects on or off.
